
## Experiment 2: Baseline vs Enhanced Prompt

### Objective
To compare a baseline prompt with an enhanced prompt using the Gemini API.

### Tools Used
- Python
- Google Colab
- Gemini API
- google-genai library

### Procedure
1. Connect to the Gemini API.
2. Send a baseline prompt about recursion.
3. Send an enhanced prompt with specific instructions.
4. Compare the generated outputs.

### Result
The experiment demonstrates how detailed prompts can improve
the structure and relevance of AI-generated responses.
